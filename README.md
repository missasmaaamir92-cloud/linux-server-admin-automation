# Linux Server Administration & Automation

## Overview

A hands-on Linux administration project using Ubuntu 24.04 LTS.
The objective is to practice server management, security,
service administration, monitoring, and Bash automation.

## Current Implementation

- Linux system information auditing
- CPU, memory, and disk usage reporting
- Network interface inspection
- Timestamped audit report generation
- Bash script execution and validation

## Technology Stack

- Ubuntu 24.04 LTS
- Linux command line
- Bash scripting
- Git and GitHub

## Project Structure

- `scripts/` - Administrative automation scripts
- `docs/` - Technical documentation
- `screenshots/` - Verified project evidence
- `logs/` - Generated audit reports

## Learning Objectives

- Understand Linux system administration
- Automate routine administrative tasks
- Monitor system resources
- Apply security best practices
- Document and troubleshoot Linux systems

## Status

In progress — additional administration,
security, monitoring, and automation tasks
will be added as they are implemented.
